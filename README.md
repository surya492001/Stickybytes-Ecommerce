# StickyBytes | Sticker E-Commerce Application

StickyBytes is an e-commerce web application where users can explore and purchase stickers through a simple shopping experience.

## Features
- **Sticker Catalog:** Browse available stickers.
- **Shopping Cart:** Add stickers to the cart.
- **Stripe Checkout:** Secure online payment integration.
- **User Authentication:** Login and logout functionality.
- **About Page:** Learn more about StickyBytes.
- **Contact Page:** Contact information and customer inquiries.

## Project Overview
StickyBytes demonstrates e-commerce application development, including shopping cart management, user authentication, payment gateway integration, and frontend and backend functionality.
